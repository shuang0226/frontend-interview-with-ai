# 优惠中心实施计划

> 依赖已确认的设计：[优惠中心浮层设计](../specs/2026-08-04-coupon-center-design.md)。

## 1. 券领域模型、演示数据与纯状态函数

- 新增 `src/types/coupon.ts`，定义券类型（普通券、APP 专享券、每月暴涨券）、领取状态、可用状态及规则说明。
- 新增 `src/data/coupons.ts`，提供普通未领取、APP 专享、已领取可用、已领取不可用和“专享券包－每月领券”五类初始样例。
- 新增 `src/utils/coupon.ts`：提供领取状态切换、生成 1–4 张新增券、替换已领取券包和为新增券生成稳定 id 的纯函数。新增券的规则说明从各自数据生成，生成函数允许注入随机数，确保单测可复现。

验证：单测覆盖普通券状态变化、不可重复领取、暴涨数量范围、规则文案和生成券 id 唯一性。

## 2. 实现券卡的跨端展示层

- 新增 `src/components/coupon-center/CouponCard.tsx` 和样式，统一展示封面占位、标题、标签、金额、有效期、操作按钮和底部说明。
- APP 专享券将“APP 专享”压在商品图片上沿左侧，并将带金色背景的“白金会员享”置于券卡右上角；标题下展示权益标签。
- 已领取可用券展示“已领取”印章和“去使用”按钮；不可用券展示置灰按钮、印章、不可用原因与覆盖整张券的灰色遮罩。
- 未领取普通券显示“领券”和规则说明；新增暴涨券从券数据读取各自的规则说明。

验证：不同券状态切换不改变券卡高度；不可用遮罩覆盖底部说明栏；印章位于右侧视觉中心。

## 3. 实现浮层、地址页入口与关闭交互

- 新增 `CouponCenterSheet.tsx`，由地址页的“打开优惠中心”底部入口控制显隐。
- 使用参考图的顶部白色浮层、四项导航、右上气泡装饰和关闭按钮；关闭只关闭浮层，保留地址列表选择与编辑状态。地址页入口改为居中按钮。
- 用 `ScrollView` 承载券列表；领取动画期间通过受控状态禁用列表滚动和再次点击，动画结束后恢复。

验证：打开后覆盖地址页，关闭回到原地址页；长券列表能上下滚动；每张已领取券无法再次领券。

## 4. 实现普通券领取反馈与每月券包暴涨动画

- 新增 `CouponFlightLayer.tsx`，用设计稿固定坐标、CSS transform 和受控 class 驱动飞行，避免依赖 DOM 查询与平台专有 API。
- 普通券领取：按钮立即变为“去使用”，临时飞行标记从按钮区域沿抛物线落至自身券图中心；落地后该卡高亮一次。
- 每月券包领取：生成 1–4 张券，并在动画完成后替换券包所在列表位置；每张红色红包样式临时飞行券按不同延迟、偏移和弧线飞向对应新增券图中心；全部落地后，全部新增券同时高亮闪烁。
- 使用 `setTimeout` 的受控清理，浮层关闭或组件卸载时取消未完成的动画状态，避免残留遮罩或滚动锁。

验证：普通券不生成新券；仅每月券包生成新券；所有飞行落点在对应券图中心；新券同时闪烁。

## 5. 集成、测试和多端构建检查

- 在地址页整合入口与浮层状态，不修改既有地址标签、编辑和选择行为。
- 扩展 Vitest，用纯函数测试覆盖领取与券包生成的主要业务路径。
- 执行 `npm run typecheck`、`npm test`、`npm run build:h5`、`npm run build:weapp`、`npm run build:alipay`、`npm run build:tt`；用 H5 手工检查浮层滚动、关闭、领取和动画。

## 实施顺序

先完成 1 的可测试状态模型，再实现 2 的静态券卡，随后完成 3 的浮层集成，最后实现 4 的领取动画并执行 5 的全量验证。每一步通过对应检查后再进入下一步。
