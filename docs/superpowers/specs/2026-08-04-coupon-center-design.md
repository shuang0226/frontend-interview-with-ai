# 优惠中心浮层设计

## 目标

在现有地址页面底部加入“打开优惠中心”入口。点击后显示覆盖地址页的可滚动优惠券浮层，复刻参考视频的优惠中心层级、券卡样式、领取状态和动画反馈。

## 页面结构

- 地址页底部入口：仅保留居中的“打开优惠中心”按钮，不显示辅助说明文字。
- 遮罩层：弱化地址页；点击关闭按钮关闭浮层，回到地址页原状态。
- `CouponCenterSheet`：参考图从页面顶部展示的白色浮层，包含标题、关闭按钮、右上“气泡装饰”、导航标签和纵向券列表。
- `CouponCard`：展示封面占位图、标题、面额、有效期、权益标签、领取状态、操作按钮和底部说明栏。
- `CouponFlightLayer`：仅在领取动画期间渲染，位于券列表上方且不接收点击。

浮层导航固定显示“我的优惠券 / 付费会员 / 代金券 / 领券”，默认选中“领券”。领取前的可见列表顺序为普通券、专享券包、APP 专享券，再接已领取或不可用券。券列表支持上下滚动；动画开始至所有落点完成期间，滚动被锁定，避免目标卡片中心发生偏移。

## 券数据与状态

每张券有稳定 `id`、标题、面额、有效期、标签、是否 APP 专享、领取状态和可用状态。

- `unclaimed`：按钮显示“领券”；普通券底部显示规则说明。
- `claimed-usable`：按钮显示“去使用”；右侧垂直居中显示“已领取”印章；底部显示规则说明。
- `claimed-unusable`：按钮显示“去使用”但置灰不可点击；整张券有半透明灰色遮罩；右侧垂直居中显示“已领取”印章；底部显示不可用原因，例如“当前餐厅不可用”。

APP 专享是券的独立展示属性：红色“APP 专享”标签绝对定位在商品图片上方的左侧，金色背景的“白金会员享”标签定位于券卡右上角，标题下显示权益标签。

## 领取与动画

### 普通券

点击未领取的普通券后，该券立刻进入 `claimed-usable`，按钮变为“去使用”。该券执行一次从领取按钮区域到自身卡片中心的抛物线提示动画，动画结束后卡片短暂高亮闪烁。已领取券不能再次领取。

### 专享券包－每月领券

仅标识为 `monthly-burst` 的“专享券包－每月领券”执行暴涨流程：

1. 点击后券包进入已领取动画状态，并禁用重复点击。
2. 随机生成 1–4 张新券；动画完成后移除券包，以新券替换其原列表位置，使领取后的列表与参考图一致。
3. 为每张新券创建红色红包样式的临时飞行卡，按不同的延迟、横向偏移和抛物线高度，从券包领取按钮附近飞向该新券商品图片的中心点。
4. 每条轨迹的终点使用固定设计稿坐标计算出的券卡中心，确保落点在券图正中间。
5. 所有飞行卡落地后，全部新增券同时高亮闪烁；每张新增券使用其自身数据配置的规则说明，不固定为同一文案。

动画使用 Taro 基础组件、固定设计宽度和受控 CSS transform 状态；不依赖 DOM 测量或平台专有动画 API。各端字体可能略有差异，但卡片位置、落点和动画顺序保持一致。

## 视觉规则

- 浮层和卡片以白底、圆角、浅灰分隔线和红色主操作色为主。
- 券封面使用灰色图片占位框；金额使用红色大号文字。
- “已领取”是带双圆轮廓与斜向文字的淡红印章，固定在券卡右侧视觉中心，样式参照图 4。
- 不可用券遮罩覆盖整张券，包括底部不可用原因栏；原因栏文字随遮罩一并呈现为弱化状态。
- 高亮使用短暂浅红背景与透明度脉冲，不改变卡片最终布局。

## 验证

- 单元测试：普通券领取、不可重复领取、暴涨券生成数量范围、生成券规则文案、状态转换和关闭浮层。
- 手工验证：关闭返回地址页；券列表可滚动；普通券与暴涨券的动画完成后目标卡片高亮；暴涨飞行终点在新券卡片中心。
- 构建验证：TypeScript、H5、微信、支付宝、抖音构建；实现只使用 Taro 支持的基础组件和样式。RN 使用同一状态与布局逻辑，需在 RN 容器中执行最终设备验收。

## 验收标准

1. 地址页可打开和关闭优惠中心浮层，关闭后地址页仍可正常操作。
2. 券列表可上下滚动，状态和提示符合各类券的规则。
3. 仅“专享券包－每月领券”暴涨 1–4 张新券，并在动画完成后由新券替换；普通券不会生成新券。
4. 飞行券的视觉落点位于对应新增券卡片的中心，全部新增券会在落地后同时出现高亮闪烁。
5. 导航、券包、APP 专享、白金会员享、已领取、不可用遮罩和规则说明样式符合提供的参考图。
