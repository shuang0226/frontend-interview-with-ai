
## 3. 设计优惠中心领取交互

```text
请优化优惠中心的领券体验：

1. 点击 [指定券包] 后，卡片需要有明确反馈动画，按钮显示“领券中...”，约 [1] 秒后完成；
2. 领取动画进行期间，底部“一键领券”也显示“领券中...”并有加载反馈；
3. 成功领取后的优惠券出现更明显的入场或高亮动画；
4. 底部“一键领券”可以领取当前页全部可领取优惠券，相关卡片按钮同步显示“领券中...”。

请将可复用的状态转换放在 `src/utils/coupon.ts`，在 `tests/coupon.test.ts` 覆盖新增分支；页面中保留动画坐标测量失败时的回退逻辑。完成后运行 `npm run typecheck` 和 `npm test`。
```

